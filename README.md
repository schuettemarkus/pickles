# Pickles

An editable King's Court points leaderboard for an 8-player pickleball weekend. It's one self-contained `index.html` with no build step and no dependencies.

- Tap **+** or **−** next to a guy's name to change his points. Rows re-sort a moment after you stop tapping.
- Set the buy-in to see the pot total, who's leading and by how much. Ties are called out.
- The **Crude** toggle swaps in each guy's nickname.
- **Copy for group chat** copies the standings as text. **Reset all** sets everyone back to 0.

Open `index.html` in a browser, or turn on GitHub Pages and open it on a phone. Saved locally, points stay on that device. As a shared Claude artifact, points sync live to every phone.
